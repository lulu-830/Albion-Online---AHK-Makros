# Albion-Online---AHK-Makros
# Albion Online AHK Macros  Eine Sammlung von AutoHotkey-Makros zur Unterstützung wiederkehrender Aufgaben im Albion Online Marketplace. Enthält Skripte für Ausrüstung, Offhands und das erneute Einstellen von Verkaufsangeboten. Entwickelt für einfache Anpassbarkeit und Erweiterung.

📖 Über das Projekt

Dieses Repository enthält eine Sammlung von AutoHotkey (AHK)-Skripten für den Albion Online Marketplace. Die Makros dienen dazu, wiederkehrende Abläufe zu vereinfachen und den Verwaltungsaufwand im Handel zu reduzieren.

✨ Features
🛡️ Armor.ahk
Unterstützung beim Verwalten von Rüstungsgegenständen.
🛡️ offhand.ahk
Hilfsfunktionen für Offhand-Gegenstände.
💰 Re Sell.ahk
Unterstützung beim erneuten Einstellen bestehender Verkaufsangebote.
📂 Projektstruktur
.
├── Armor.ahk
├── offhand.ahk
├── Re Sell.ahk
└── README.md
⚙️ Voraussetzungen
Windows
AutoHotkey v1.x oder v2 (je nach verwendetem Skript)
🚀 Verwendung
AutoHotkey installieren.
Dieses Repository herunterladen oder klonen.
Das gewünschte .ahk-Skript starten.
Den Anweisungen im jeweiligen Skript folgen.
🔧 Anpassungen

Alle Skripte können individuell angepasst werden, beispielsweise:

Hotkeys ändern
Timings anpassen
Neue Funktionen hinzufügen
Weitere Handelsabläufe automatisieren
